# Модерация и администрирование

## Модерация событий

Перед публикацией каждое событие проходит проверку администратором.

**Процесс:**

```
Организатор отправляет событие на модерацию
              ↓
Администратор рассматривает заявку
              ↓
   Одобрено                 Отклонено
      ↓                         ↓
Событие публикуется    Организатор получает
                       уведомление с комментарием
```

Администратор видит список всех заявок на согласование и может фильтровать их по статусу.

## Журнал действий

Администратору доступен журнал действий в системе — история значимых операций пользователей. Позволяет отслеживать активность и разбирать спорные ситуации.

## Управление пользователями

Администратор может просматривать список всех пользователей системы.
