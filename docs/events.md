# Управление событиями

## Что такое событие

Событие — это хакатон или соревнование, которое организатор создаёт и ведёт через несколько стадий. При создании задаются:

- название, описание и дата начала
- минимальный и максимальный размер команды
- этапы события и задачи для участников
- призовой фонд, теги и обложка
- соглашение об участии (если требуется подпись)
- автоматическое распределение участников по командам

## Жизненный цикл

```
Черновик → На модерации → Опубликовано → Начато → Завершено
```

| Статус | Описание |
|--------|----------|
| **Черновик** | Событие только создано, редактируется организатором |
| **На модерации** | Отправлено на проверку администратору |
| **Опубликовано** | Видно всем участникам, открыта регистрация |
| **Начато** | Мероприятие идёт, регистрация закрыта |
| **Завершено** | Все операции завершены |

## Что может организатор

- Создать событие и заполнить все параметры
- Редактировать черновик
- Перевести событие по статусам (требует модерации перед публикацией)
- Загрузить обложку события
- Удалить событие

## Что может участник

- Просматривать опубликованные события
- Присоединиться к событию
- Подписать соглашение об участии
- Участвовать в чате события
- Покинуть событие
