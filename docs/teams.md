# Команды и проекты

## Типы команд

| Тип | Вступление |
|-----|------------|
| **Открытая** | Любой участник события может вступить сразу |
| **Закрытая** | Нужно отправить запрос — владелец его принимает или отклоняет |

## Роли в команде

- **Владелец** — создатель команды. Принимает или отклоняет заявки на вступление в закрытую команду
- **Участник** — член команды. Общается в командном чате, участвует в событиях

## Операции с командой

- **Создать команду** — выбрать название и тип (открытая/закрытая)
- **Найти команду** — просмотр списка команд с фильтрацией
- **Вступить** — в открытую сразу, в закрытую — через запрос
- **Покинуть** — выйти из команды в любой момент

## Запрос на вступление в закрытую команду

```
Участник отправляет запрос
       ↓
Владелец принимает → участник добавляется в команду
       ↓
       или
       ↓
Владелец отклоняет → участник получает уведомление
```

Участник может отменить свой запрос до принятия решения.

## Проект команды

В рамках участия в событии команда может вести проект:

- описание выполненной работы
- прикреплённые файлы
- ссылка на ветку Git-репозитория (обновляется по запросу)
